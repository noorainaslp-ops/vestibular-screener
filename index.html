Based on the rule-based algorithm published in Ryu, H.T., Callejas Pastor, C.A., Joo, J.S., Ku, Y. & Suh, M.-W. “A rule-based mobile screening classifier for six ICVD-defined vestibular disorders: a pilot study,” Scientific Reports 16, 25032 (2026). This independent web implementation is offered for educational purposes and has not itself been clinically validated. यह स्क्रीनिंग Ryu, H.T., Callejas Pastor, C.A., Joo, J.S., Ku, Y. एवं Suh, M.-W. द्वारा प्रकाशित नियम-आधारित एल्गोरिद्म पर आधारित है: “A rule-based mobile screening classifier for six ICVD-defined vestibular disorders: a pilot study,” Scientific Reports 16, 25032 (2026)। स्कोरिंग लॉजिक संबंधित cecy07/vestibular-classifier रिपॉज़िटरी (MIT लाइसेंस) से लिया गया है। यह स्वतंत्र वेब कार्यान्वयन केवल शैक्षिक उद्देश्यों के लिए है और स्वयं क्लिनिकल रूप से मान्य नहीं किया गया है।
