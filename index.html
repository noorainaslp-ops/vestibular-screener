Based on the rule-based algorithm published in Ryu, H.T., Callejas Pastor, C.A., Joo, J.S., Ku, Y. & Suh, M.-W. “A rule-based mobile screening classifier for six ICVD-defined vestibular disorders: a pilot study,” Scientific Reports 16, 25032 (2026). Scoring logic ported from the companion repository, cecy07/vestibular-classifier (MIT license). This independent web implementation is offered for educational purposes and has not itself been clinically validated.
